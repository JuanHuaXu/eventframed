discarding75% of potential observations. This new consumed-data shadow diagnostic
preserves that negative result and adds one predeclared arm to the three controls.

For each eligible released pair, use the frozen full-input forecast iff its
pre-outcome random Audit flag is true; otherwise use the original bounded-view
forecast. Reference and live receive the SAME view-selection rule. Feed exactly
one resulting correctness pair to one existing Bayesian monitor and one external

predictor, identically distributed independent reference/live inputs under null,
and common independent Bernoulli audit nomination. Given the chosen view,
reference and live correctness have equal expectations, so their bounded
difference retains the original gate's zero-mean null. Arbitrary covariate or
selection shifts are not covered by that statement.

cohorts, no forward split-count reduction in either, and no added stable splits.
Report after-horizon flush detections separately. Do not change parameters on
failure. This is a signal-availability rescue, not evidence of forecast-quality
gain, formal target-law-diameter coverage, or completion of goal3. Closed-loop
