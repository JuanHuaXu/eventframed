# Native Public Retrieval Fit Diagnostic

2026-10-04. Frozen before any official query reaches the isolated native daemon.
The preceding nativepool-v6 technical pilot is complete, not a quality result.
All seven whole goals remain OPEN. No production changes or confirmation use.

Import ALL 5,183 original source documents through the audited document pooling
contract and existing InsertText RPC. Use the same installed Q8 GGUF model,
owned daemon environment/socket, direct launch and priority 10 as nativepool-v6.
Retain its sampled 2 GiB daemon RSS ceiling; the total client context is now
20 minutes for the full corpus and 351 fit-only queries. RPC concurrency one,
one attempt and 30 seconds per request remain unchanged. Failures, partial
imports and per-query output are preserved; they are not complete evidence.

Project exactly the 351 original fit query IDs using the frozen family split.
The native client accepts ONLY this projection, corpus and its owned root.
Do not pass labels, official mixed query file, calibration or confirmation to
the predictor. Query order is the original fit plan order, not performance.
The runner hashes all inputs and the complete local Go dependency closure before
building/running, then verifies them afterwards. No fitting or model selection
occurs in this diagnostic. The public pretrained model may know the benchmark.

For each fit query, request SearchTextCollections K=200, record the ENTIRE actual
returned set and bind every identity/text/source/clock/span envelope. Request
RankCandidates K1=K2=that set's cardinality. Reject shortened, duplicate or new
rows; no top10 packing before the entire returned frontier has been ranked.
Empty or fewer-than-50 nominations are recorded as a nomination limitation,
not padded with gold sources or silently treated as the promised 50-200 frontier.
The nativepool-v6 log already shows raw8 -> returned1 under post-L7 processing;
this does not prove L7 is erroneous or justify guessed configuration overrides.
Native scores are search-order signals, not probabilities or certified truth.

Persist actual per-import wall time, raw request/response traces, binding and
rank wall time, total acquisition/import time, and owned process terminal state.
Model logs report a 512-token context: full framed source is supplied, but
full model-side consumption is NOT established by source coverage. Preserve
any input-length errors or evidence of truncation instead of hiding them.

Only AFTER all predictions are terminal may a separate evaluator open the
official training citation labels, restricted to the exact fit projection.
Report query-macro citation recall in the returned frontier and top10, MRR@10,
nDCG@10, actual candidate cardinality, and request latency distribution. Count
missing/empty predictions as failures, never drop hard queries. Fit diagnostics
are descriptive, not adoption tests, simultaneous certificates, agent accuracy,
or untouched-quality evidence. Citation relevance is NOT support, correctness,
causal identification or memory usefulness. Calibration180/confirmation300
remain unopened by prediction/evaluation. A later independently frozen learned
candidate and held-out comparison are required for Goal5.

This is a full native baseline, not a rescue or a substitute for the seven goals.
No benchmark-specific query rewrite, alternative nomination, threshold tuning,
model switch or fallback is permitted after observing this run.
