## Declared Joint Model

Each member has a static noise state H in {0,.1,.2}, prior (.8,.1,.1), and a
changing rate state Z with 22 atoms: the supplied baseline (mass .8) plus the
21-point grid z/20 with a .2-weight finite Polya prior preserving the baseline
mean. The grid distribution is beta-binomial(20,b,1-b). Members are independent
in this model. Static noise and independent members are modeling assumptions,
not claims about all generators or causal structure.

At each member's issued ordinal, Z persists with probability 15/16 and otherwise
resets to its prior. H never resets. The first state has the joint prior.
Y_n is Bernoulli at the current rate; W1 and W2 are conditionally independent
noise-corrupted measurements of the SAME Y_n. A second receipt replaces the
first-only emission likelihood by the joint W1/W2 likelihood at its original
ordinal. Filtering replays a bounded suffix; retrospective queries smooth the
origin using only receipts already visible. The target is this member's next
clean Y, uniformly weighted over all 150 members. No current or future hidden
labels, availability or arrival times enter nomination.

All laws, likelihoods and acquisition values come from this single finite model.
Predictive value is the expected squared movement of the next clean forecast
under both possible W2 outcomes, divided by member count. The tower identity
must hold within 2e-10. Information is mutual information with the 66 origin
states; falsification is expected Gini-concentration gain over those states,
not an Anti-Pigeon certificate or causal falsification guarantee. Uncertainty
is entropy of W2. Random selection does not evaluate candidate scores.

The 1/16 transition probability is a fixed nominal 16-round persistence model,
not optimized using V64 quality labels. This is a new hypothesis on a CONSUMED
cohort, not an untouched validation. No finite noise/prior grid can be assumed
to represent an external stream exactly. Evidence is retained up to 64 issued
trials per member; there is no 600-position expiry. Old rate evidence is
attenuated through transitions, while evidence about static noise can persist.
No inference beyond the explicit 2..200-member/64-trial caps is promised.
