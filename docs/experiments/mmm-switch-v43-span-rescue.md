# V43 unit-emission span rescue

Prospective computational rescue, not a new statistical hypothesis or quality
claim. Preserve initial, cached-constant and log-only FAIL cost artifacts.

For T=(1-alpha)I+alpha*1*pi, T^k=(1-alpha)^k I+
(1-(1-alpha)^k)*1*pi. Pending and cancelled positions have unit emissions.
Store forward messages at revealed positions only; compose each intervening
unknown span with this identity. Binary search finds the preceding revealed
anchor. An out-of-order label inserts an anchor and recomputes EVERY later
revealed anchor from original cached advice, never from arrival-order advice.
The first original position still uses pi with zero preceding transitions.
No pending position is treated as evidence or removed from the time scale.

Prediction costs O(log T + N); resolution costs O(T + N*K), where K is the
number of revealed positions at/after the new arrival and O(T) is bounded
index insertion/movement. Worst-case replay remains O(N*T), not constant time.
Persistent/scratch/index memory remains O(N*T); all expert cost is extra.
Unit-transition composition changes floating-point evaluation, not the model;
independent full-history/path tests keep the existing3e-12 tolerance.

cancelled spans, zero/full/tiny hazard, private original forecasts, atomic
failed insertion and epoch reset controls before interpreting cost. Use the
