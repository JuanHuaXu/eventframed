## What changed

`internal/researchregimeledger` mechanically forks V78 inference and replaces
the journal. Pending queries and accepted reveals use the SAME frozen support
history. Issue preserves earlier masks and appends an as-of mask selected before
observations. Its receipt reports clean-Y AND observed-W1 probabilities under
that mask; it does not reuse the old unrestricted next-event forecast. Arrival
does not insert a latent transition. A support refresh is explicit, increments
the support epoch, and invalidates outstanding publication tokens. Reveal changes
the evidence/law version without silently changing the support epoch. Snapshot
and query outputs own their data. The publication fingerprint includes evidence,
configuration, support, version, epoch and as-of clock.

This is a restricted conditional WORKING law, not recovery of omitted original
joint probability. A refresh is an approximation step, not ordinary conditioning.
Any rejected query branch causes explicit abstention; errors are never silently
assigned zero probability. A supported actual update can still proceed when the
alternative query branch is unsupported. Numerical probability underflow also
rejects instead of inventing zero mass. No likelihood floor or hypothesis revival.

## Preserved failed attempts and bug hunt

`initial` stopped at unit failure: the test wrongly required different next
forecasts under a guaranteed global reset. `repaired` stopped at another unit
failure: an OLD event also cannot affect the CURRENT state after intervening
guaranteed resets. The final fork uses the latest issued event, requires its
current posterior to change, and separately requires the next reset forecast
to remain unchanged. These are corrected limiting-case tests, not relaxed
oracle tolerance or a rescued scientific failure. Raw snapshots/logs remain.

`latest-fork` passed unit/race/vet, then benchmark failed on a genuinely
unsupported latest second-measurement branch. The final benchmark separately
names successful first/second queries and witnessed second-query abstentions;
it does not replace or hide that model limitation.

fingerprint mismatch, acceptance of a joint expansion with the wrong model

Regressions cover empty readback/refresh, invalid dimensions, unsupported and
