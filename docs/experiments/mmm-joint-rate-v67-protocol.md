# V67 Rate-Transition Ablation

Diagnostic, NOT rescue/adoption/confirmation. V66 quality harm is confirmed,
but its unique cause is not: stale-baseline resets, independent member learning
with only 16 trials/member, and noise/prior misspecification remain competing
explanations. A controlled parameter contrast can isolate the effect of the
transition, not prove which alternative model will succeed. No production patch.

Keep the EXACT V66 joint model, finite prior, noise law, source queues, chooser,
score and gates. The only change is the declared hazard: static 0, nominal 1/16,
and memoryless 1. These are boundary/negative controls, not label-selected values.
For EACH of all 40 consumed worlds and three delays, run no_pair and uncertainty
under each hazard: 720 arms, 96,000 underlying Y. No extra independent outcome
count, fitting, new seeds or sealed labels. Each paired arm still requests 400
W2 measurements; no_pair is a resource ablation, not matched observation cost.

Static tests retention without reset. Memoryless removes rate persistence
entirely: clean next-law must stay at its supplied baseline, although static
noise can still learn. Nominal MUST be bitwise identical to V66 in all non-cost
fields (240 arms). All 40 populations must remain identical. Independently replay
ALL 720 arms and their issued clean/W1 marginals, nominations, receipts, posterior
queries, missingness, snapshots and metrics with the dense reference. Existing
hazard-boundary component tests are retained. Record full lifecycle cost; no
backend/concurrent serving, RSS or equal-total-cost superiority assertion.

This is an ablation after observing V66 outcomes. It can suggest further research,
but selecting the best member of this contrast cannot create untouched evidence.
Use the original V66/Full/Adaptive quality and recovery gates unchanged. Preserve
every failure and the previous complete frozen run. All seven whole goals OPEN.
