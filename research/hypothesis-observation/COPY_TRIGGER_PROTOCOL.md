# Copied-source trigger diagnostic

Freeze the risk-budget policy and reference normalized entropy. Audit every
nonterminal count state and every state reachable under either policy, without
using actual regimes for action selection. Classify differences by renewal
count and whether source0 has any outcome opposite its initial report.

Hypothesis: every reachable early decision difference (prior renewals0..4)
requires such a contradiction, impossible when source0 is root-copied. A
reachable early difference without that contradiction falsifies this hypothesis.
Do not conflate early agreement with terminal forecast agreement: action at
prior renewal5 changes final risk but not pre-query learning-area loss.

Additionally propagate exact integer outcome-path multiplicities under every
copy mask. A copied source allows only its root outcome; a fresh source allows
both outcomes. For noise strictly between0 and.5, all allowed finite paths have
positive likelihood. Compare entire count-state occupancy maps of the two
policies at each step, not merely summed risk. Identical maps through step5
imply identical area loss for any such noise with the same frozen forecast map.
This support argument is combinatorial and avoids numerical sign inference.

Full replay, all frozen source hashes, compiler statistics, and negative-control
fresh masks are recorded. It proves a property only of these frozen policies,
not a universal acquisition impossibility or a correctness claim about copying
in real evidence. Do not modify production or old artifacts.
