# Prospective Git-manual retrieval fusion v1

2026-10-03. Frozen BEFORE any model retrieval on this fixture. All seven full
goals remain open. This is public, outcome-labeled retrieval support for agent
questions, not generated answers or executed Git tasks. Commands in facts are
DATA ONLY; no reset, clean, push, checkout or other Git mutation is executed.

## Reasoning Gate

Confirmed symptoms: NASA sparse transfer lost literal top1, RFC priority lost
packet survival, NARA packet-set preservation still lost top1. Causes remain
unidentified: lexical mismatch, arbitrary score scales/ties, and packing or
nomination loss are competing explanations. A rank-only fusion is a research
recommendation, not a confirmed daemon repair. No upstream runtime patch or
production change is proposed. It uses the existing research-only hook.
Falsifiers: top1/survival losses, law changes, or no fresh-domain gains.

## Arms And Integration

baseline: unchanged Recall. incumbent: hook passthrough of input rank order.
lexical: descending frozen ASCII six-field union coverage (feature7).
rrf: combine incumbent and lexical permutations, stable incumbent lexical ties.
protected: same RRF, put incumbent positions1..10 strictly before outsiders.
All feature extraction uses 5W1H, NOT full-text content/metadata. Hook input
ORDER is the incumbent rank; its Baseline field is usefulness, not rank score.

RRF follows Cormack, Clarke and Buettcher (SIGIR2009),
[primary paper](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf):
v=(61/2)*(1/(60+r_inc)+1/(60+r_lex)). Offset60 is not tuned here.
Protected scores=.5+.5*v inside first10, .5*v outside. Values are search-order
utilities, never calibrated probabilities. Stable ties retain incumbent order.
Caps200 frontier; O(n log n) time/O(n) memory. No labels, fit, ID lookup,
per-question rules, network or journal I/O in scorer. It cannot nominate missed
records. Protected prefix is NOT a final packet or top1 non-harm guarantee:
default evidence occupancy and token budget packing still operate afterward.

New isolated service/store per query/arm,48 CaptureTurns, query-only fresh
session, no feedback/learning, fixed times. Recall50/pack10/token budget10000.
Default pack occupancy remains ON in every arm. No OpenClaw/LLM execution.
Loopback installed Nomic137M/F16/768 with frozen digest
0a109f422b47e3a30ba2b10eca18548e944e8a23073ee3f3e947efcf3c45e59f.
Exact bounded512-entry role-separated memo reuses vectors across arms.
Warm Recall timing excludes embedding misses; acquisition reported separately.
Prewarm fixed corpus through first baseline capture; each question prewarmed
before timed Recall. No embedding timing advertised as end-to-end latency.
Five arms rotate by question to reduce systematic serial warm-up bias.
Every frontier/packed law and stored journal must agree; hook rows record
input lexical coverage and scores for independent formula audit.

## Frozen Gates And Uncertainty

Technical prerequisites: all500 cases collected; input/output valid unique IDs;
incumbent packet/order parity with baseline; frontier sets and corrected laws
identical across arms; journaling agreement; exact hook arithmetic, prefix-set
property, fixture/source freeze and no future-label access. Any failure makes
the quality screen invalid rather than an improvement.

Primary candidate protected: each split must have >=2 net positive-query top1
gains versus baseline, zero literal top1 losses, zero support-survival losses,
and a positive one-sided95% lower bound on mean command-cluster top1 gain.
Exploratory rrf uses the same screen, reported separately, not substituted if
primary fails. Lexical is a simpler control, not tuned or selected afterward.
Intervals: command-cluster paired t bounds (df7, t=.95 quantile1.894578605);
two-sided95% t intervals (2.364624252), descriptive and assumption-dependent.
Also report exact discordant-cluster sign tests, cluster vectors, gain/loss
counts, reciprocal rank, nomination and final packet survival by wording.
No100 independent-trial CI or repeated-monitoring guarantee is claimed.
Absent controls have no support and are NOT counted as correct abstention
merely because packets are unrelated. Report returned-record count explicitly.

Performance: three component benchmark repetitions at10/50/200 candidates;
full warm service Recall median/p95/p99/max by arm, extraction+sort callback
time, total capture time and uncached embedding acquisition. Goal6 loaded,
durable serving/freshness is not established. No source revision after outputs
except independent auditor repairs, with any such repair separately recorded.
Failed screens remain failed, and data become consumed after the run.
