# What-field lexical comparator

Freeze before computing outcome comparisons. Reuse actual saved frontiers from
five task-aware service artifacts. Compare recorded ordinary and task-aware
top1, offline lexical-only order, and task-priority-then-lexical order. The
lexical comparator consumes only effective query, canonical what-field text and
numeric score for ties. Combined order uses the original task plan's class
partition; it never changes predicate logic. Corpus IDs join labels only AFTER
ordering. No fresh embeddings, generated answers or outcome learning.

Fixed score: binary term-vector cosine with smoothed frontier IDF, English
alphabetic tokens, common function-word removal and generic suffix stripping.
Numbers are omitted; calendar predicates remain a separate task-plan input.
This is not a full morphological analyzer or semantic relation model. No launch,
arrival or landing dictionary is present. Scores are ranking features only.

All fixtures are consumed. Require no lost task-aware positive case in any set
and an improvement over6/10 on landing positives for a combined design pass.
Report lexical-only controls too, absent cases separately, and every regression.
Do not infer actual packing/lifecycle compatibility from this offline top1
calculation; integration and proper packing still require tests. Save all
per-query orders and scores with source hashes to a NEW output path.
