# Semantic-role paired retrieval diagnostic

Frozen before execution. Twelve designed questions share two previously verified
public Rosetta facts. Six logical roles each have opposite chronological pairs:
positive selection, polar verification, falsification, contracted negation,
explicit negation and quoted-claim explanation. Dates/facts are not novel;
questions extend the already consumed counterexample families. This is a design
diagnostic, not independent confirmation, natural-user prevalence or a learning
experiment. No oracle annotation enters the ranking call.

Compare ordinary focused retrieval with current fast temporal priority using
priority-overlay-v2, identical local embedding model, fresh memory per question,
recall50, pack1, diversity on, budget10000 and no outcome updates. The corpus
contains no answer-generating assistant completions. Read oracle after all calls.
Measure top1 support, baseline regressions and rescues by logical role. Verify
full-frontier law/score equality and explanation/journal binding. A single lost
correct baseline case rejects universal priority safety; no minimum improvement
or rescue claim is assumed. Do not alter cases after inspecting scores.

Retain24 raw result rows and source hashes. Timing is diagnostic only; no loaded
service latency or adaptive-expansion benchmark is intended. A role-aware rescue
must be a separately frozen variant and preserve this negative control.
