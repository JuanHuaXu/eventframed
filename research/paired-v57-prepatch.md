# Prediction-value implementation gate

Classification: RECOMMENDATION, not a production defect or confirmed failure of
the declared concentration objective. The source criterion is implemented
correctly; its target can differ from future prediction usefulness.

Evidence: V54/V56 observation selection yields tiny loss advantages and no
equal-total-cost win. Independent finite joint tables show a settled global
class with useful member-local information. Alternatives include dynamics/prior
mismatch, delayed evidence, and excessive acquisition cost. Eighteen finite
identities support the narrower target-mismatch possibility, not an external
causal explanation or general empirical rescue.

Boundary: isolated new research package only. No production paths, no stored-data
repair, no upstream bug patch, no private data or untouched task labels. Reuse
the current joint model, original-position paired-outcome factors, pending and
epoch semantics. The new statistic may change choices intentionally, but cannot
change the forecast law for a fixed evidence stream. Existing V56 code remains
frozen. Public experimental-design research supplies the decision-utility
principle, not an EventFrame theorem or numerical speed guarantee.

Invariant: for the declared next-issue clean targets and frozen nonnegative
weights, expected squared movement equals the same-model expected reduction
in Bayes Brier risk. Hypothetical measurements must not be committed. Failed
requests must leave authoritative and cache state unchanged. Future target
labels, generator rates, and hidden source availability are not API inputs.
Second measurements still measure the original Y, not a fresh independent Y.

Lifecycle: evaluate only resolved first-measurement tickets without a requested
second measurement. Old tickets use their original slot while later revealed
evidence remains in the posterior. Pending first outcomes remain unrevealed.
Canceled, foreign, repeated, or old-epoch origins must fail closed. Queries are
single-owner snapshots, like the base learner, not concurrent mutation APIs.

Initial complexity: one batch builds M*84 component means; each candidate runs
two original 84*21*T hypothetical integrations, full marginal normalization,
and dense M*84 prediction reweighting. Charge all construction and candidate
work. This first reference implementation makes no low-latency claim.

Falsifiers/tests: independently rebuild joint histories with both possible
second outcomes and verify probabilities, future means, tower identity, and
risk difference; check delayed arrivals, already-paired later trials, canceled
and pending frames, full-noise support, changed global evidence, and epoch
ownership. A law difference on an unchanged evidence stream is a regression.
Model value can still fail to improve external risk; preserve that outcome in
the later all-regime experiment. Do not optimize only favorable cells.
