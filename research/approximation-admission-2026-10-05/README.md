# Approximation admission mechanism audit

This folder contains synthetic component regression and matched prepared-operation
timings, not new scientific confirmation or production promotion. The immutable
v83 control is revision `7a7b9357c06ce855795b947ffcde2fd61a82d3ca`.
The current sources are snapshotted with SHA-256 before testing in temporary
minimal modules. The live checkout, daemon defaults and private datasets are not
used or changed. Reproduce from the repository root with
`node research/approximation-admission-2026-10-05/run.mjs`.

The analytic recurrence and cap-region corollary are exact-arithmetic statements.
Directed scalar-bound calculations require justified input bounds. The inference
engine itself remains floating point; the new opt-in guard requires a separately
justified complete numerical budget. A named budget alone does not prove it.
Without such coverage the guard fails closed. Old query evidence-ratio weights
are outside the clean-forecast bound and deliberately absent from guarded output.

Prepared 150/200-member issue/query operation timings exclude setup, full history
ingestion, durable stores, scheduling, remote I/O and loaded request tails. Run
order alternates but is not randomized. Dense and rational audits are code checks
on declared synthetic inputs, not independent replication or factual truth.
